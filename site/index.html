CSS only

Clock mode · no JavaScript, no pagereel code

Four rows of CSS keyframes. pagereel pauses every animation and places it at each frame's time, so the render is exact and loops.

pagereel render examples/css-only/index.html --duration 6 -o css-only.mp4

Canvas sketch

Clock mode · requestAnimationFrame, performance.now, Math.random

An ordinary animation loop with 1,400 particles. The virtual clock drives its frames and seeds its randomness, so parallel workers produce one seamless video.

pagereel render examples/canvas/index.html --duration 8 -o canvas.mp4

One Shape

Scene mode · pagereel/motion springs, pagereel/audio soundtrack

A 12-second UI film where one shape morphs through five states. The page paints any moment with seek(t); picture and synthesised sound share one beat grid. Unmute it.

pagereel render examples/one-shape/index.html --root . -o one-shape.mp4
